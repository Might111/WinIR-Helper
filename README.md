# WinIR-Helper

WinIR-Helper 是一款基于 PowerShell 编写的 Windows 应急响应信息收集辅助脚本，主要用于帮助蓝队人员在应急响应初期快速采集主机基础信息、发现可疑线索，并辅助完成后续人工研判。

当前最新版本：**v0.3-beta**

---

## 项目定位

WinIR-Helper 并不是一款自动化查杀工具，也不直接替代 D盾、河马、EDR、杀毒软件等专业安全工具。

本工具主要用于：

- 快速收集 Windows 主机应急响应基础信息
- 辅助分析登录日志、账户、启动项、计划任务和网络连接
- 在 Web 入侵场景中识别 Web 目录、Web 日志和可疑请求
- 提取隐藏账户、攻击者 IP 候选和挖矿 IOC
- 汇总重点关注项，方便后续人工分析和专业工具复核

简单来说：

```text
WinIR-Helper：负责快速收集线索
D盾 / 河马 / EDR：负责专业检测和查杀
人工分析：结合日志、账户、文件、进程和 IOC 做最终研判
