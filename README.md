# WinIR-Helper

基于 PowerShell 的 Windows 应急响应信息收集脚本，用于辅助蓝队人员在应急响应初期快速采集主机基础信息，并进行初步风险筛查。

当前最新版本：**v0.2**

---

## 功能

- 4624 登录成功日志导出
- 4625 登录失败日志导出
- 来源 IP 统计
- 疑似高危 IP 筛选
- 本地用户检查
- 管理员组成员检查
- 启动项检查
- 计划任务检查
- 当前网络连接检查
- 危险端口初筛
- 重点关注项汇总
- 采集摘要生成

---

## v0.2 更新内容

相比 v0.1，v0.2 主要优化了两个问题：

1. **管理员权限检测增强**  
   非管理员权限下默认退出，避免 Security 安全日志读取失败后继续生成误导性结果。

2. **危险端口初筛降噪**  
   将危险端口结果拆分为：
   - 全部危险端口记录
   - 高危端口监听
   - 可疑外联连接
   - 重点关注项

## 使用方式

建议以管理员身份运行 PowerShell：

```powershell

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\WinIR-Helper.ps1
自定义日志范围和高危 IP 阈值：

.\WinIR-Helper.ps1 -Days 30 -FailedThreshold 20

测试非管理员模式：

.\WinIR-Helper.ps1 -AllowNonAdmin

注意事项
本工具仅用于授权环境下的安全分析、蓝队学习和应急响应练习。
脚本输出结果只作为初步筛查依据，不能直接作为最终研判结论。
请勿上传真实应急环境中的敏感日志、IP、账号信息或客户数据。
