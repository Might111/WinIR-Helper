# WinIR-Helper v0.5.3-beta：挖矿配置追踪增强版

本版本为 v0.5.3-beta 测试版，重点增强挖矿配置追踪能力，并继续保留 HTML 报告内置的离线文件 Hash 计算器。

## 核心更新

### 1. 挖矿配置追踪增强

相比 v0.5.2，本版本不再只依赖进程名称或固定挖矿目录，而是结合以下线索进行关联分析：

- 资源异常进程
- 可疑服务安装
- 可疑计划任务
- 可疑启动项
- 启动文件夹脚本
- 可疑命令行参数
- 配置文件路径

工具会根据这些线索反向追踪可疑目录，并在安全范围内对父目录和兄弟目录进行轻量扫描，以发现隐藏在相邻目录中的配置文件、日志文件、矿池地址和钱包地址。
